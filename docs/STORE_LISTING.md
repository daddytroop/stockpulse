# Play Store listing

Ready-to-paste text for **Play Console → Grow → Store presence → Main store listing**.
Play ranks apps on the words in the title, short description and full
description, so the words people search for ("stock tracker", "dividend
tracker", "portfolio", "stock charts", "widget") are used naturally and
more than once. Ratings matter just as much: the app now asks for one,
once, on a good day.

## App name (30 characters max)

```
Stock Pulse: Dividend Tracker
```

## Short description (80 characters max)

```
Track stocks & dividends, pro candlestick charts, widgets. No account needed.
```
